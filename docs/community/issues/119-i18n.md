# Issue #119: Internacionalización (i18n)

## Descripción
Soporte multiidioma (ES/EN base, extensible a más idiomas).

## Descripción técnica

- **Librería**: `i18next` + `react-i18next` (ligero, maduro, TypeScript).
- **Estructura de traducciones**:
  ```
  apps/web/public/locales/
  ├── es/
  │   ├── common.json      # UI general (botones, labels, tooltips)
  │   ├── geometry.json    # Términos técnicos (módulo, entrepaño, bisagra)
  │   ├── errors.json      # Mensajes de error (GeometryErrorCode)
  │   └── ui.json          # UI específica (toolbar, paneles)
  └── en/
      ├── common.json
      ├── geometry.json
      ├── errors.json
      └── ui.json
  ```
- **Configuración i18next**:
  ```typescript
  // src/lib/i18n.ts
  import i18n from 'i18next';
  import { initReactI18next } from 'react-i18next';
  
  i18n.use(initReactI18next).init({
    lng: 'es',                    // default
    fallbackLng: 'en',
    interpolation: { escapeValue: false },
    resources: { es: {...}, en: {...} },
    detection: {
      order: ['localStorage', 'navigator', 'htmlTag'],
      caches: ['localStorage'],
    },
  });
  ```
- **Hook de uso**: `useTranslation()` en componentes.
  ```tsx
  const { t } = useTranslation('common');
  <button>{t('save')}</button>
  ```
- **Selector de idioma** en TopBar (bandera + código ISO).
- **Detección automática**: `navigator.language` → `localStorage` → fallback `es`.
- **Pluralización**: `t('module_count', { count: n })` → "1 módulo" / "2 módulos".
- **Interpolación**: `t('width_changed', { width: '2400 mm' })`.

## Criterios de aceptación

- [ ] `i18next` + `react-i18next` instalado y configurado.
- [ ] Estructura `public/locales/{es,en}/{common,geometry,errors,ui}.json`.
- [ ] Hook `useTranslation` funcionando en componentes.
- [ ] Selector de idioma en TopBar (bandera + código ISO).
- [ ] Detección automática: `navigator.language` → `localStorage` → fallback `es`.
- [ ] Pluralización funcionando (`t('module_count', { count: n })`).
- [ ] Interpolación funcionando (`t('width_changed', { width })`).
- [ ] Persistencia en `localStorage` (`i18nextLng`).
- [ ] Tests unitarias (cambio idioma, pluralización, interpolación).

## Áreas afectadas

- `apps/web/package.json` (dependencias: `i18next`, `react-i18next`)
- `apps/web/src/lib/i18n.ts` (configuración)
- `apps/web/public/locales/es/` y `en/` (archivos JSON)
- `apps/web/src/components/studio/TopBar.tsx` (selector idioma)
- `apps/web/src/components/**/*.tsx` (migración a `t()` keys)
- Tests unitarias (cambio idioma, pluralización, interpolación)
